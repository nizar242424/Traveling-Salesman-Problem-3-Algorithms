 Traveling Salesman Problem Solver with 3 Metaheuristics

A Python implementation comparing three metaheuristic algorithms for solving the Traveling Salesman Problem (TSP), featuring:
- Genetic Algorithm (GA)
- Simulated Annealing (SA) 
- Particle Swarm Optimization (PSO)

Features
- Genetic Algorithm with ordered crossover and swap mutation
- Simulated Annealing with geometric cooling schedule
- Particle Swarm Optimization with velocity clamping
- Interactive visualization of solutions
- Algorithm comparison metrics (distance, runtime, iterations)
- CSV export for results analysis
- Light/dark mode toggle
